### David Krakauer — edit

Target: Skill lost under high tool availability doesn't return easily when access is cut, so competence comes first.
Skill lost under high tool availability doesn't return easily when access is cut. Recovery takes far more than abstaining, and no one knows whether a dependent population can recover. So competence comes first, but that alone is not enough. Transparency is the other axis. A tool whose working can be rebuilt in the mind, like a map, can be used early. An opaque tool, like satellite navigation or a model too large to internalize, erodes competence however skilled the user. How much tool availability learners face is a policy choice, not a personal one. A fixed share of the pool funds preregistered withdrawal tests: take the tool away and see whether scholars can still catch the error.
